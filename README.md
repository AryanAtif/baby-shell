# Unix Shell
`unix-shell` is simple dumbed down shell for the unix-like operating systems.

The shell supports command execution fine, but I'm planning to improve it further in the future by allowing support for environment variables and piping of multiple commands, though that isn't really my priority for now, since I don't think I'd really learn anything new trying to implement those functions.

So anyway this is how the project will be for now. If you have any suggestion on how should I improve the code or anything like that, please open up an issue.
